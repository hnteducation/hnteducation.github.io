Cấu Hình Kết Nối API

Kết nối trang web này tới Google Sheets của bạn.

Lưu ý: Mật mã này được thầy thiết lập trong mã Apps Script và được lưu an toàn tại trình duyệt cá nhân của thầy, hoàn toàn không lưu trên GitHub Pages.

Hướng dẫn sửa lỗi kết nối chập chờn:

  • Kiểm tra Deploy: Đảm bảo thầy đã chọn **Triển khai mới (New deployment)** chứ không chỉ bấm chạy thử (Test deployment - vốn yêu cầu quyền đăng nhập Google).
  • Quyền truy cập: Ở mục *Who has access (Ai có quyền truy cập)*, thầy bắt buộc phải chọn **Anyone (Mọi người)**. Nếu chọn *Only me* hoặc *Anyone with Google account* thì hệ thống từ web sẽ bị Google chặn.
  • Ủy quyền Google Drive: Trong lần đầu deploy, thầy phải bấm *Ủy quyền truy cập* (Authorize) và bấm chọn tài khoản Google của mình để cho phép code can thiệp vào Sheets và Drive.
  • Lỗi code sheet: Hãy chắc chắn thầy dán code từ file bound script bên trong Google Sheet chứ không phải file script độc lập ở ngoài Drive.

Xác nhận: Lên Lớp Hàng Loạt?

Thao tác này dùng khi bắt đầu một năm học mới. Hệ thống sẽ:

  • Tăng Khối lớp của tất cả học sinh đang học thêm 1 cấp (Ví dụ: Khối 8 -> Khối 9).
  • Chuyển trạng thái các học sinh lớp 12 thành "Nghỉ luôn" (Đã tốt nghiệp).

LƯU Ý: Dữ liệu trên Google Sheet sẽ được cập nhật trực tiếp. Thầy nên tải file backup JSON trước khi bấm xác nhận.
